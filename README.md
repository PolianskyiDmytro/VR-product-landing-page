# 🚀 VR Product Landing Page

A responsive landing page of an imaginary VR product built according to a Figma design.
The project focuses on clean layout structure, scalable styling, and modern frontend practices using BEM and SCSS.

## 🚀 Features
- Fully responsive layout (desktop, tablet, mobile)
- Pixel-perfect implementation based on Figma
- Semantic and accessible HTML structure
- BEM methodology for scalable CSS
- SCSS for better styling organization
- Clean and maintainable code structure

## 🛠️ Tech Stack
- HTML5
- SCSS (Sass)
- BEM methodology
- npm

## 🎯 Purpose
This project was created to practice building complex landing pages, improve responsive design skills, and apply scalable CSS architecture using BEM and SCSS.
